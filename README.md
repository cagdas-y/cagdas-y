## 👋 About Me

I am a **Bilişim Teknolojileri** graduate based in **İzmir, Türkiye**, focused on **Artificial Intelligence, Android Development, Web Development, and Python**.

As the founder and developer behind **Shypact** (`shypact.com`) and the **Shywish** Android application, I enjoy turning ideas from initial architecture and UI/UX design into working, tested, and shippable products.

- **Focus Areas:** Native Android apps with Jetpack Compose, modern web applications & APIs, Python automation, and foundational Machine Learning / AI systems.
- **Engineering Approach:** Start with simple, maintainable architecture, measure performance before optimizing, prioritize security by design, and iterate through real testing.
- **Workflow:** `Design → Build → Test on Device → Measure → Refine`
